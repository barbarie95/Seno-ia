Nouvelle fiche

Importer plusieurs fiches

Colle un tableau JSON de fiches. Les retours à la ligne dans une réponse s'écrivent \n. L'import n'est pas comparé aux fiches déjà enregistrées : cherche d'abord pour éviter les doublons.

Voir un exemple 
[
  {
    "question": "Donne-moi des informations sur le Gabon",
    "reponse": "🇬🇦 **Gabon** : fiche rapide\n\n- 🏛️**Capitale** : Libreville",
    "mots_cles": "Gabon, gabonais, Libreville",
    "categorie": "Pays",
    "pays": "Gabon",
    "reponse_exacte": true,
    "actif": true
  }
]

Limites d'utilisation

Les réponses issues de la base de connaissances ne sont pas comptées.

Chaque recherche utilise 1 crédit Tavily : vérifie ton offre Tavily avant d'augmenter ce plafond.

Les images ont leur propre compteur : elles ne sont pas comptées dans les messages.

Le quota gratuit de Cloudflare permet environ 170 images par jour (estimation) : garde une marge sous ce chiffre.
